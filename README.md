# AlertDesktop 🇺🇦

Десктопний клієнт для оперативного моніторингу повітряних тривог в Україні на базі **Electron**.

Застосунок розповсюджується **вільно та безкоштовно** як відкрите програмне забезпечення під ліцензією [Apache 2.0](LICENSE).

---

## 🚀 Основні можливості

- **Інтерактивна мапа тривог:** Відображення актуальної карти тривог сервісу `alerts.in.ua` в ізольованому безпечному контейнері (`WebContentsView`).
- **Миттєвий фоновий моніторинг:** Підтримка прямого WebSocket-з'єднання з сервером-шлюзом або NEPTUN (0s затримки) чи періодичного опитування API (вбудований шлюз, UkraineAlarm, Alerts.in.ua, Ubilling Aerial Alerts, NEPTUN, JAAM).
- **Інтеграція в системний трей Windows:**
  - 🟢 **Зелена іконка:** Відбій / немає загрози в обраному регіоні.
  - 🔴 **Червона іконка:** Активна повітряна тривога або загроза обстрілу.
  - ⚪ **Сіра іконка:** Офлайн / відсутність зв'язку з сервером.
- **Звукові та нативні сповіщення:** Системні спливаючі повідомлення Windows та налаштовувані аудіосигнали (сирени, гонги, дзвіночки) при початку та відбої тривоги.
- **Гнучка географічна фільтрація:** Ієрархічний вибір локації: **Область → Район → Громада** або моніторинг усієї України.
- **Адаптивний дизайн:** Автоматичне узгодження темної та світлої теми інтерфейсу.
- **Автозапуск та фонові оновлення:** Підтримка автозапуску при старті Windows та інтегрований модуль автооновлення з GitHub Releases (`electron-updater`).

## 🛠️ Встановлення та розробка

### Вимоги
- [Node.js](https://nodejs.org/) (версія 18 або новіша)
- [npm](https://www.npmjs.com/)

### Швидкий запуск
```bash
# Клонування репозиторію
git clone https://github.com/suprun/alert_desktop.git
cd alert_desktop

# Встановлення залежностей
npm install

# Запуск у режимі розробки
npm start
```

### Тестування та перевірка синтаксису
```bash
npm test
```

### Збірка Windows-інсталятора
```bash
# Створити готовий NSIS Setup файл у папці dist/
npm run dist
```
